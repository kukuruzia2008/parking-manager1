# Parking Manager v17 — мобильный чек-лист

## Проверка на узком экране

- [ ] Шапка не перекрывает первый экран и учитывает вырез/островок iPhone.
- [ ] Нижняя навигация показывает шесть разделов и не перекрывает содержимое.
- [ ] Поля ввода не вызывают нежелательное автоувеличение Safari.
- [ ] Карточки, формы, модальные окна и схема парковки помещаются по ширине.
- [ ] Кнопки удобно нажимать большим пальцем.

## Проверка навигации в безопасной демонстрации

- [ ] На опубликованном HTTPS-адресе Safari запрашивает разрешение на геопозицию.
- [ ] Маршрут строится до выбранной парковки.
- [ ] На мобильном экране сверху отображается следующий манёвр.
- [ ] В нижней панели отображаются оставшееся расстояние, время и ETA.
- [ ] Голос можно включить/выключить, изменить скорость и повторить подсказку.
- [ ] Завершение навигации останавливает обновления геопозиции и озвучку.
- [ ] После установки PWA на экран «Домой» приложение открывается в режиме standalone.

## Важное ограничение

Проверять интерфейс можно без движения — в режиме просмотра маршрута или на неподвижном устройстве. Не проводите испытания, требующие взаимодействия с телефоном во время управления транспортом. Веб-версия не гарантирует GPS при заблокированном экране или в фоне. Для этой функции нужна отдельная нативная iOS-реализация с Core Location background mode.
